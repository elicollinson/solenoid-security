# Public dataset cohorts

These are canonical JSONL **detection** cohorts. The label `injection` means an attempted prompt injection appears in untrusted material; it does not mean an agent followed the instruction. The versioned manifests pin each generated file and its upstream source commit and SHA-256. Rebuild with `python3 evals/scripts/import-public-datasets.py --web-repo … --aib-repo … --dojo-repo …` using those exact upstream commits. The importer refuses changed upstream files.

## Get the datasets

From a fresh repository checkout, run `bun run eval:fetch-public` (or `python3 evals/scripts/fetch-public-datasets.py`). This clones the three public upstream repositories at the exact commits in the manifests into ignored `.local/eval-sources/`, checks their Git revisions and source-file SHA-256 hashes, then regenerates and verifies the three canonical JSONL files. The generated files are gitignored and are not part of this repository branch. Git, Python 3, and network access to the public sources are required; no model provider credentials or calls are needed.

For an offline rebuild from existing pinned checkouts, pass `--web-repo`, `--aib-repo`, and `--dojo-repo` to `fetch-public-datasets.py`. Each checkout must be at its manifest's commit. Then run `bun run eval:test` to exercise the case-level tests. Without the generated files, those tests are explicitly skipped while the manifest pin test still runs.

Source files contain attack text. These labels should be analyzed **per dataset and per facet** rather than pooled into one headline rate. The web cohort is observed public web material, AgentInjectionBench is synthetic, and the AgentDojo subset is template-derived. No live model or provider call is made by the import script or its tests.

Dry-run any condition with the suite `evals/suites/prompt-injection-public-datasets-v1.json`, for example:


## Varied prompt-injection cohorts (2026-10-08)

These cohorts address a design limit of the long-document results: LongPIBench uses one fixed attack sentence per template per domain (about 12 sentences across 2,272 cases). They add varied and subtle attacks, more surfaces, and benign controls that contain legitimate instructions. All are `canonical-jsonl` with stable opaque IDs, origin-tagged turns, `prompt_injection_attempt` labels, facets and text hashes. Generated cases live under ignored `evals/private/sources/`; manifests pin the upstream commit or revision, every source file's SHA-256, the license and the class counts. Importers refuse changed upstream files and verify the generated bytes against the manifest. None calls a model.

Rebuild (no model calls; sources go to ignored paths):

```sh
# Git sources: BIPIA, Inj-QA and RepoGuardBench clone into .local/eval-sources; AgentDojo reuses bun run eval:fetch-public's checkout
python3 -B evals/scripts/import-bipia-table-code.py --fetch
python3 -B evals/scripts/import-inj-qa.py --fetch
python3 -B evals/scripts/import-repoguard.py --fetch
uv run --no-project --python 3.12 --with-editable .local/eval-sources/dojo --with pyyaml==6.0.3 --with pydantic==2.14.0 \
  python -B evals/scripts/import-agentdojo-suites.py
# Hugging Face sources: download the manifest's pinned files (resolve/<revision>/<file>) into
# evals/private/upstream/{browsesafe-bench,nemotron-ipi,llmail-inject}/, then:
uv run --no-project --python 3.12 --with pyarrow==21.0.0 python -B evals/scripts/import-browsesafe.py
python3 -B evals/scripts/import-nemotron-ipi.py
python3 -B evals/scripts/import-llmail-pool.py            # needs the LongPIBench upstream (import-longpibench.py)
python3 -B evals/scripts/build-longpi-template-cohorts.py
bun test ./evals/tests/varied-injection-datasets.test.ts
```

AgentDojo ground-truth replay and BrowseSafe's Parquet are the only steps that need packages beyond the standard library; pinned versions are given above. Middle insertion for BIPIA and Inj-QA replaces upstream's random or NLTK choice with a SHA-256 choice, as recorded in each manifest. Clean LongPIBench siblings in the subtle and LLMail-email cohorts are byte-identical to the clean cases of `longpibench-*-default-v1`. Report them separately, or reuse them with `--deduplicate-inputs --reuse-inputs-from`; do not count them twice.

**Not imported:** BIPIA WebQA (NewsQA/CNN) and Summarization (XSum/BBC), whose sources need separately licensed, non-redistributable downloads; IssueTrojanBench (non-commercial/no-derivatives); Gray Swan arena data (restricted terms). No external benign-instruction sets (agentic boundary pairs, PromptShield benign rows, BrowseSafe distractors as a separate cohort, SEP probes) are used; the authorized controls are repository-authored.

Suite: `evals/suites/prompt-injection-lmstudio-studio-baseline-q8-t4096-extension-v1.json`. Its engines, strategies, rules and conditions are byte-identical to the running Studio baseline, so the two can be compared directly. Dry run:

```sh
bun evals/scripts/run-lmstudio-matrix.ts --suite=evals/suites/prompt-injection-lmstudio-studio-baseline-q8-t4096-extension-v1.json --conditions=baseline-ornith-q8-t4096-full
```
